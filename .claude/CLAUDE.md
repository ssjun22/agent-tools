Claude Code 환경에서 사용하는 스킬, 서브 에이전트, 훅, 룰, 플러그인, 프롬프트를 관리하는 중앙 저장소. 다른 프로젝트에서 `.claude/`에 심볼릭 링크하여 사용한다.

## 디렉토리 구조

```
agents/          에이전트 정의 (.md)
skills/          스킬 패키지 (카테고리별 하위 폴더)
  dev/           개발 도구 (코드 리뷰, 커밋, 템플릿 등)
  design/        UI/UX 디자인
  log/           기록/로그/회의
  meta/          스킬·에이전트·플러그인 자체 개발
  pipeline/      개발 워크플로우 파이프라인
  planning/      계획/문서 작성
  project/       프로젝트/이슈 관리
plugins/         스킬+에이전트+룰+훅을 묶은 배포 단위
prompts/         재사용 프롬프트 라이브러리
hooks/           세션 이벤트 자동화 스크립트
rules/           행동 규칙 (.md)
scripts/         검증·유틸리티 스크립트
```

새 스킬/에이전트/플러그인 작업 시 `skills/`, `agents/`, `plugins/`를 우선 탐색한다.

## 작업 규칙

- 새로 만들기 전에 동일 카테고리의 기존 파일을 먼저 읽고 패턴을 따른다.
- 스킬/에이전트/플러그인은 특정 프로젝트에 종속되지 않는 범용 형태로 작성한다.
