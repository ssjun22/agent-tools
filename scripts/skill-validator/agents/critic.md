다음 작업을 수행해.

## 목표

- 스킬 패키지의 품질을 비평하고 개선안을 제시해 debate-log.md 끝에 append 해.
- 컨텍스트 비용을 불필요하게 키우지 마. (핵심 근거/핵심 이슈만)

## 입력

- $WORK_DIR/
- $LOG

---

# 1) 파일 수집 및 로딩 (컨텍스트 비용 관리)

1. $WORK_DIR/ 디렉토리의 트리를 먼저 요약해라.
   - 파일/폴더 목록을 작성해라(경로 포함).
   - SKILL.md 존재 여부를 확인해라(없으면 Blocker로 기록).

2. debate-log.md를 읽어라.
   - 마지막 Round 번호를 파악해 Round N을 결정해라(N = 마지막 Round + 1).
   - 직전 라운드의 Blocker/High 이슈를 5개 이하로 요약해라(중복 지적 방지 목적).

3. SKILL.md는 전문을 읽어라(필수).

4. 번들 리소스는 “필요한 만큼만” 읽어라(Progressive Disclosure).
   - references/: SKILL.md에서 직접 언급/참조되는 파일을 우선 읽어라. 대용량이면 관련 섹션만 발췌해라.
   - scripts/: 실행하지 말고, 용도/입출력/엔트리포인트/주의사항 파악에 필요한 부분만 읽어라.
   - assets/: 바이너리(이미지/폰트 등)는 열지 말고 파일명/용도만 기록해라. 템플릿 텍스트 파일만 필요한 경우 일부를 읽어라.

5. 비평 출력에는 원문 인용을 최소화해라.
   - 근거 인용은 1~2문장(또는 25단어 이내)로 제한해라.
   - “위치”에 파일 경로 + 섹션 헤딩(가능하면) 또는 라인/블록 식별자를 남겨라.

---

# 2) 비평 차원 (5개)

아래 5개 차원으로 스킬 전체를 비평해라.
각 차원에서 최대 3개, 전체 최대 12개의 핵심 이슈만 기록해라(중복/사소한 항목 나열 금지).

| 차원                                      | 평가 내용                                                                                                                                                                                                                                                                                      |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Context Economy & Progressive Disclosure  | SKILL.md가 핵심 절차/규칙만 담고 있는가. 장황한 설명/중복이 있는가. references/scripts/assets로 적절히 분리되어 컨텍스트 비용이 관리되는가. 대용량 references에 대한 탐색(검색 패턴/로드 가이드)이 있는가                                                                                      |
| Packaging & Trigger Fidelity              | frontmatter(name/description/license) 적합성. description이 자동 활성화 판단에 충분히 구체적인가(오탐/미탐 위험). disable-model-invocation 필요성이 드러나는가(필요한데 누락됐는가). 폴더 구조(SKILL.md, scripts/, references/, assets/)가 표준에 맞고 SKILL.md에서 리소스를 실제로 참조하는가 |
| Role Focus & Scope Control                | 스킬의 1차 역할이 단일하고 선명한가. 너무 많은 문제를 해결하려고 범위가 확장돼 있는가. Non-goals(하지 않는 것)가 명시돼 역할 경계가 닫혀 있는가. 다른 스킬/일반 작업으로 위임해야 할 것을 끌어안고 있지 않은가                                                                                 |
| Human-in-the-loop Checkpoints             | 사용자 확인이 필요한 지점이 명시돼 있는가(입력 부족/불확실성/권한/덮어쓰기/파괴적 변경). “멈추고 질문”해야 하는 조건이 구체적인가. 필수 입력(자료/자산/정책/경로 등) 부족 시 추측 대신 요청하도록 설계돼 있는가                                                                                |
| Verification, Determinism & Observability | 완료/성공 조건이 객관적으로 검증 가능한가(테스트/체크리스트/산출물). 출력 형식이 재현 가능하게 고정돼 있는가(스키마/필드). 반복 실행 시 누적 손상 방지(멱등성/중단 조건/최대 반복). 실패 시 원인/다음 액션/디버깅 힌트가 제공되는가(관측성)                                                    |

> 참고: 기존 차원(Workflow Completeness/Output Specification/Guardrails/Writing Style)은 위 5개 안에 포함해 평가해라.  
> 예) Workflow 분기/엣지케이스 → Verification/Observability 또는 Role Focus 안에서 지적.  
> 예) Writing style(명령형/2인칭 금지) → Packaging 또는 Context Economy에서 “문서 규칙 위반”으로 기록.

---

# 3) 심각도 기준

- Blocker: 스킬이 안전/신뢰성/기본 작동 측면에서 출시 불가(트리거 치명 오탐, 패키징 불능, 파괴 위험 무방비, 검증 불가 등)
- High: 주요 사용성/재현성/운영 안정성에 큰 악영향(명확한 실패 가능성 존재)
- Medium: 품질 개선 필요(성공은 가능하나 흔들림/비효율)
- Low: 문체/형식/가독성 등 사소한 개선

---

# 4) debate-log.md에 append 할 형식

debate-log.md 끝에 다음 형식으로 append 해라.

### Round N - Critic

| #   | 차원 | 심각도 (Blocker/High/Medium/Low) | 위치 | 문제 | 개선 방향 |
| --- | ---- | -------------------------------- | ---- | ---- | --------- |
| 1   | ...  | ...                              | ...  | ...  | ...       |

작성 규칙:

- “문제”는 [NEW] 또는 [PERSIST] 태그로 시작해라.
  - [PERSIST]: debate-log에서 이미 지적됐는데 아직 남아있는 문제
  - [NEW]: 이번 라운드에서 새롭게 발견한 문제
- “개선 방향”은 실행 가능한 변경으로 써라(어느 섹션에 무엇을 추가/삭제/이동/명시할지).
- Human-in-the-loop 관련 이슈는 최소 1개 이상 반드시 점검/기록해라(없으면 “명시 누락”을 이슈로 기록해라).

**수렴 신호**: [많은 근본 문제 / 중간 수준 개선 필요 / 소폭 다듬기만 필요]

수렴 신호 판단 가이드:

- 많은 근본 문제: Blocker ≥ 1 또는 High ≥ 3
- 중간 수준 개선 필요: Blocker = 0, High 1~2 또는 Medium 다수(≈4개 이상)
- 소폭 다듬기만 필요: High = 0, Medium 소수(≤3), 나머지 Low 중심
