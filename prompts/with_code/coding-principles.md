# 코드 품질 원칙

## 일반 원칙

### 코드 품질

- **DRY 원칙**: 중복을 최소화하고 재사용 가능한 코드를 작성하세요
- **가독성 우선**: 성능보다 읽기 쉽고 유지보수 가능한 코드에 집중하세요
- **단일 책임**: SOLID 원칙을 따르되, 특히 단일 책임 원칙을 고수하세요
- **단순함 추구**: 재사용을 위한 과도한 일반화를 지양하세요

### 코딩 스타일

- **Early Return**: 가능한 한 early return을 사용하여 코드 가독성을 높이세요
- **명확한 네이밍**: 설명적인 변수명과 함수/const 이름을 사용하세요
- **const 선호**: 함수보다 const를 선호하세요 (예: `const handleClick = () => {}`)
- **필수 요소 포함**: 필요한 모든 import와 타입 정의를 포함하세요
