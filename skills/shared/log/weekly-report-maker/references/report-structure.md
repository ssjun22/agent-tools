# 보고서 작성 가이드

주간 업무 보고서의 각 섹션별 작성 방법과 예시입니다.

## 진행 상황 (Progress)

**목적:** 이번 주에 완료한 작업과 현재 진행 중인 업무를 구체적으로 기술합니다.

**작성 팁:**
- 완료한 작업과 진행 중인 작업을 구분
- 구체적인 결과물이나 성과 명시
- 필요 시 진행률(%) 포함
- 간결하지만 명확하게 작성

**예시:**
```markdown
### 진행 상황

**완료:**
- 사용자 인증 API 개발 완료 (JWT 기반)
- 데이터베이스 스키마 설계 및 마이그레이션 적용
- 프론트엔드 로그인 페이지 구현

**진행 중:**
- 관리자 대시보드 개발 (70% 완료)
- 성능 테스트 환경 구축 중
```

## 이슈 (Issues)

**목적:** 발생한 문제, 블로커, 해결한 이슈를 기록합니다.

**작성 팁:**
- 문제 상황 간략 설명
- 해결 방법 또는 현재 상태
- 도움이 필요한 경우 명시
- "없음"도 괜찮음

**예시:**
```markdown
### 이슈

**해결:**
- API 응답 속도 저하 문제 → 캐싱 적용으로 해결 (평균 200ms → 50ms)
- 배포 파이프라인 실패 → 환경 변수 설정 오류 수정

**진행 중:**
- 외부 API 연동 시 타임아웃 발생 → 재시도 로직 구현 중
- 프로덕션 서버 메모리 부족 → 인프라 팀과 협의 중

**없음:**
없음
```

## 미팅 내용 (Meetings)

**목적:** 주요 회의 내용과 결정사항을 기록합니다.

**작성 팁:**
- 회의록 파일을 참조하는 것이 가장 좋음
- 회의 날짜와 참석자 명시 (선택)
- 주요 논의사항과 결정사항 요약
- 액션 아이템 포함

**예시:**
```markdown
### 미팅 내용

**2026-02-03 - 주간 스프린트 회의**
- 참석: 팀 리더, 백엔드 개발자 3명
- 논의:
  - 다음 스프린트 목표 확정
  - API 설계 리뷰
- 결정사항:
  - GraphQL 대신 REST API 사용
  - 배포 주기를 주 2회로 변경
- 액션 아이템:
  - [홍길동] API 문서 작성 (~ 2/10)
  - [김철수] 테스트 커버리지 80% 달성

**2026-02-05 - 고객사 미팅**
- 주요 요구사항 변경 사항 논의
- 일정 조정 필요: 릴리스 1주 연기

**미팅 없음:**
이번 주 미팅 없음
```

## Git 커밋 이력 (참고)

**목적:** 코드 변경 내역을 참고자료로 제공합니다.

**자동 생성:** `analyze_commits.py` 스크립트가 자동으로 생성하므로 수동 작성 불필요

**예시:**
```markdown
## 참고: Git 커밋 이력

### 프로젝트 A
- [2026-02-03] feat: 사용자 인증 API 추가 (5 files, +234/-12)
- [2026-02-03] refactor: 데이터베이스 쿼리 최적화 (3 files, +45/-89)
- [2026-02-04] fix: 로그인 오류 수정 (1 file, +5/-3)
- [2026-02-05] docs: API 문서 업데이트 (2 files, +150/-0)

**통계:** 15 commits, 47 files changed, 523 insertions(+), 89 deletions(-)

### 프로젝트 B
- [2026-02-02] feat: 대시보드 초기 구현 (8 files, +456/-0)
- [2026-02-04] test: E2E 테스트 추가 (4 files, +123/-5)

**통계:** 8 commits, 23 files changed, 234 insertions(+), 156 deletions(-)
```

## 작성 모범 사례

### DO ✅
- 구체적이고 측정 가능한 내용 작성
- 완료/진행 중 상태 명확히 구분
- 이슈는 해결 방법과 함께 기록
- 팀원이나 상위자가 이해할 수 있는 용어 사용

### DON'T ❌
- 너무 기술적이거나 전문적인 용어만 사용
- "열심히 했습니다" 같은 추상적 표현
- 코드 스니펫이나 디버그 로그 전체 복사
- 개인적인 감정이나 평가 포함

---

## 길이 가이드

- **진행 상황:** 5-10줄 권장
- **이슈:** 3-7줄 권장 (없으면 "없음")
- **미팅 내용:** 회의당 3-5줄 요약 또는 회의록 전체

---

보고서는 **명확성과 간결성**의 균형이 중요합니다. 상위자가 5분 안에 전체 상황을 파악할 수 있도록 작성하세요.
