# Claude Agent Reviewer

Claude Code 서브 에이전트 프롬프트를 점검하고, 심각도 기반 이슈 리포트를 반환하는 스킬.

기대하는 에이전트 구조는 `references/prompt-template.md`를 참조.
평가 기준은 `references/review-criteria.md`를 참조.
평가의 이론적 근거는 `references/prompting-principles.md`를 참조.
개선 제안 시 삽입 가능한 스니펫은 `references/prompt-building-blocks.md`를 참조.

## 리뷰 워크플로우

구조 점검과 내용 리뷰를 분리하여 2단계로 진행한다.

### Phase 1. 구조 점검

1. 대상 프롬프트 파일을 읽고 기존 섹션을 식별한다
2. `prompt-template.md`의 기대 구조(Frontmatter + Role, Instructions, Constraints, Output Format, Checklist)와 대조한다
3. 누락된 섹션, 기대 구조에 매핑되지 않는 내용을 식별한다
4. 구조가 일치하면 Phase 2로 진행한다
5. 구조가 불일치하면 차이를 설명하고 재배치 방안을 제안한 뒤 **여기서 멈춘다**
   - 사용자가 구조를 정리한 후 다시 리뷰를 요청하면 Phase 1부터 재실행한다

### Phase 2. 내용 리뷰 (구조 일치 시에만)

1. `review-criteria.md`의 공통 기준을 모든 본문 섹션에 적용한다
2. 각 섹션의 고유 기준을 적용한다
3. 아래 출력 포맷으로 이슈를 보고한다. 각 이슈에 개선 스니펫을 포함한다

## 심각도 정의

| 심각도      | 의미                            | 예시                                                  |
| ----------- | ------------------------------- | ----------------------------------------------------- |
| **error**   | 기능 오류를 유발할 수 있는 문제 | 필수 필드 누락, 스키마 불일치, 필수 섹션 누락         |
| **warning** | 성능 저하를 유발할 수 있는 문제 | 모호한 판정 기준, 과잉 강조 표현, 오탐 방지 규칙 부재 |
| **info**    | 스타일/관례 개선 제안           | 동기 부여 누락, 부정 프레이밍, 간결성 개선            |

## 출력 포맷

Phase에 따라 출력 포맷이 다르다.

### Phase 1 출력 (구조 불일치 시)

    ## Structure Review: [대상 이름]

    현재 구조:
    - [기존 섹션 나열]

    기대 구조와의 차이:
    - [차이 설명]

    재배치 제안:
    - [기존 섹션/내용] → [기대 섹션]으로 이동
      (재배치 스니펫)

구조가 일치하면 Phase 1 출력 없이 Phase 2로 바로 진행한다.

### Phase 2 출력 (내용 리뷰)

이슈가 없는 심각도 레벨은 생략한다.
전체 이슈가 없으면 "이슈 없음"으로 보고한다.

    ## Review: [대상 이름]

    ### error (N건)
    - **[섹션]**: [이슈 설명] → [개선 제안]
      (개선 스니펫)

    ### warning (N건)
    - **[섹션]**: [이슈 설명] → [개선 제안]

    ### info (N건)
    - **[섹션]**: [이슈 설명] → [개선 제안]
