# Prompt Reviewer

AI 에이전트 시스템 프롬프트를 점검하고, 이슈 리포트를 반환하는 범용 스킬.

평가 기준은 `references/review-criteria.md`를 참조.

## 리뷰 워크플로우

구조 점검과 내용 리뷰를 분리하여 2단계로 진행한다.

### Phase 1. 구조 점검

1. 대상 프롬프트 파일을 읽고 기존 섹션을 식별한다
2. `review-criteria.md`의 Phase 1 기준(역할/목적, 지시사항, 제약/경계, 출력 형식, 불확실성 정책)과 대조한다
3. 누락된 요소를 식별한다
4. 모든 요소가 존재하면 Phase 2로 진행한다
5. 누락된 요소가 있으면 어떤 요소가 빠졌는지 보고하고 **여기서 멈춘다**
   - 사용자가 구조를 보완한 후 다시 리뷰를 요청하면 Phase 1부터 재실행한다

### Phase 2. 내용 리뷰 (구조 충족 시에만)

1. `review-criteria.md`의 Phase 2 기준 7개 항목을 순서대로 적용한다
2. 각 항목의 감지 기준에 해당하는 이슈를 모두 수집한다
3. 도구가 없는 프롬프트의 경우 "도구 통합" 항목은 N/A로 처리한다
4. 해당하는 이슈가 없는 항목은 생략한다
5. 아래 출력 포맷으로 보고한다

## 출력 포맷

Phase에 따라 출력 포맷이 다르다.

### Phase 1 출력 (구조 미충족 시)

    ## Structure Review: [대상 이름]

    누락된 요소:
    - [누락 요소명]: [왜 필요한지 설명]
    - ...

    보완 제안:
    - [어떤 내용을 추가하면 되는지 안내]

구조가 충족되면 Phase 1 출력 없이 Phase 2로 바로 진행한다.

### Phase 2 출력 (내용 리뷰)

전체 이슈가 없으면 "이슈 없음"으로 보고한다.

    ## Review: [대상 이름]

    ### [기준 항목명] (N건)
    - [이슈 설명]
      - before: [현재 표현]
      - after: [개선 제안]

    ### [기준 항목명] (N건)
    - [이슈 설명]
      - before: [현재 표현]
      - after: [개선 제안]

    ---
    총 N건의 이슈 발견.
