# Feedback Harvesting

사용자 메시지가 다음 중 하나에 해당하면 `feedback-harvester` 서브 에이전트를 백그라운드로 실행하라:

- 현재 사용 중인 스킬/에이전트의 동작에 대한 부정적 피드백
- "왜 ~하지 않았어?", "~해야 하는데", "~는 잘못됐어" 류의 교정 표현
- 특정 규칙이나 패턴에 대한 명시적 선호/비선호 표현

## 서브 에이전트 실행 시 전달 정보

- 피드백 메시지 원문
- 현재 활성 스킬/에이전트 이름 (추론 가능한 경우)
- 피드백 대상 분류:
  - `skill` — `.claude/skills/<name>/` 하위 파일
  - `agent` — `.claude/agents/<name>.md`
  - `rule` — `.claude/CLAUDE.md` 또는 `.claude/rules/<name>.md`

## 판단 기준

### 피드백으로 감지해야 하는 표현

- "왜 ~ 안 했어?", "왜 ~ 하지 않았어?"
- "~ 하지 마", "~ 하면 안 돼"
- "~ 해야 해", "~ 해줘야 하는데"
- "~ 가 더 나아", "~ 를 선호해"
- "이건 잘못됐어", "이건 아닌데"
- "다음부터는 ~ 해줘"

### 피드백이 아닌 것 (무시)

- 단순 작업 지시: "파일 만들어줘", "테스트 돌려줘"
- 질문: "이거 어떻게 동작해?"
- 확인: "좋아", "계속 진행해"

## 실행 방법

```
Task 도구 사용:
- subagent_type: "general-purpose"
- run_in_background: true
- prompt에 피드백 원문, 대상 분류, 활성 스킬/에이전트 정보 포함
```
